# Constrained optimization and rigidity

MATLAB code accompanying *A Constrained Optimization Approach for Constructing Rigid Bar Frameworks with Higher-order Rigidity* by Xuenan Li, Christian D. Santangelo, and Miranda Holmes-Cerfon. [Read the paper on arXiv](https://arxiv.org/abs/2509.23072).

The [code guide](code/README.md) maps Figures 2–5 to the corresponding examples and links to the MATLAB run instructions.
